# v0.1.0 Acceptance Checklist

Use this checklist to decide if the repository is release-ready.

Security references:

- `docs/sandbox-mvp-spec.md`
- `docs/test-matrix.md`
- `docs/golden-path-e2e.md`

## CLI and UX

- [ ] `agent` starts successfully in interactive mode.
- [ ] `agent fix <task>` executes the full task loop.
- [ ] `agent explain <file>` provides clear, contextual output.
- [ ] Diff previews are readable and consistent.
- [ ] Startup and first-response latency are documented.

## Agent Runtime

- [ ] Golden path in `docs/golden-path-e2e.md` passes end-to-end.
- [ ] Context assembly stays within configured token budget.
- [ ] Tool call loop handles multi-step tasks reliably.
- [ ] Runtime errors surface with actionable messages.

## Tools and Safety

- [ ] All writes are diff-first; no direct overwrite path.
- [ ] Permission modes (`safe`, `workspace`, `full-access`) are enforced.
- [ ] `safe` mode blocks shell and external network calls.
- [ ] Unsafe commands are denied by allowlist policy.
- [ ] Workspace path restrictions are enforced.

## Sandbox Enforcement (Phases 1-4)

| Requirement | Mode | Expected Behavior | Status |
| --- | --- | --- | --- |
| Permission authorization enforced before tool execution | All | Runtime rejects unauthorized tools | [ ] |
| Workspace path boundary enforced | All | Filesystem access restricted to workspace root | [ ] |
| Traversal attempts rejected (`../`) | All | Runtime denies tool call | [ ] |
| Symlink escape prevented via canonicalization | All | Runtime denies external path | [ ] |
| Write target parent validation enforced | WorkspaceWrite / FullAccess | New file writes restricted to workspace | [ ] |

## Patch Safety Enforcement

| Requirement | Expected Behavior | Status |
| --- | --- | --- |
| Mutation tools return patch proposals | Runtime rejects direct mutation payloads | [ ] |
| Diff preview displayed before apply | Visible CLI diff | [ ] |
| Confirmation required before apply | Prompt shown | [ ] |
| ReadOnly mode blocks patch apply | Patch rejected | [ ] |
| Conflict detection prevents overwrite | Runtime rejects conflicting patch | [ ] |
| Patch application logged | Audit entry produced | [ ] |

## Shell Command Enforcement

| Requirement | Mode | Example | Expected Behavior | Status |
| --- | --- | --- | --- | --- |
| Shell execution disabled | ReadOnly | `git status` | denied | [ ] |
| Allowlisted command allowed | WorkspaceWrite | `git status` | allowed | [ ] |
| Non-allowlisted command denied | WorkspaceWrite | `curl https://example.com` | denied | [ ] |
| Allowlist bypass permitted | FullAccess | `bash build.sh` | allowed | [ ] |

## Manual Runtime Validation

Run local sanity checks:

- `agent run-command "git status"` -> allowed in workspace mode
- `agent run-command "curl https://example.com"` -> denied in workspace mode
- `agent run-command "bash build.sh"` -> allowed in full-access mode
- mutation tool call -> diff preview shown -> apply prompt required before file mutation
